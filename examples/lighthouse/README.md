# Lighthouse Lifestyle — Next.js Rendering Host

## Overview

The Next.js (App Router) rendering host for the Lighthouse Lifestyle demo site, integrated with Sitecore XM Cloud via the Content SDK.

## How to Run Locally

Follow the [root README — How to Run Locally](../../README.md#how-to-run-locally), using this path: **`examples/lighthouse`**.

From the repo root:

```bash
cd examples/lighthouse
npm install
npm run dev
```

Open **http://localhost:3000**.
